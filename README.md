One real-life patch note, in the style of a comedy changelog: v3.2.1 fixed the bug where sneezing while driving closed both eyes for 0.4 seconds at highway speed.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt`.

The entry text is 99 Unicode code points long.
